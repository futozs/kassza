```ts
kassza.invoices.create(input: CreateInvoiceInput, options?: { signal?: AbortSignal }): Promise<CreatedInvoice>
```

A kassza a bemenetből `xmlszamla` XML-t épít, és `multipart/form-data` POST kérésben, az `action-xmlagentxmlfile` form mezőben küldi el a `https://www.szamlazz.hu/szamla/` címre. A mellékletek az `attachfile1` … `attachfile5` mezőkbe kerülnek.

Kötelező csak a **vevő** (`buyer`) és legalább egy **tétel** (`items`). Minden más mezőnek van alapértéke, vagy elhagyható.

<Callout type="tip">
  Az alábbi táblázatokban az **XML elem** oszlop a Számla Agent mezőjét mutatja, így a hivatalos
  dokumentáció bármelyik mezőjét megtalálod a kasszában. A kassza az elemeket az XSD által előírt
  sorrendben írja ki.
</Callout>

<Callout type="warning" title="Ne használd más vevő azonosítóját">
  Az `identifier` alapján a Számlázz.hu összekapcsolja a vevőt a partnertörzs bejegyzésével, és
  frissíti annak adatait. Ha egy azonosító két vevőhöz tartozik, a vevői fiók linkjével az egyik
  vevő a másik bizonylatait is láthatja. Egy azonosító mindig csak egy vevőé legyen.
</Callout>

## Tételek (items)

Minden tételnél a `name`, a `vat` és pontosan egy ár kell: `netUnitPrice` vagy `grossUnitPrice`. A nettó, áfa és bruttó értéket a kassza számolja ki a [kerekítési szabályok](/docs/szamla-letrehozas/beallitasok-es-szabalyok/kerekites) szerint.

| Mező | XML elem | Alapérték | Leírás |
| --- | --- | --- | --- |
| `name` | `megnevezes` | – | **Kötelező.** A tétel megnevezése. |
| `vat` | `afakulcs` | – | **Kötelező.** Áfakulcs, például `27` vagy `'AAM'`, lásd [Áfakulcsok](/docs/szamla-letrehozas/beallitasok-es-szabalyok/afakulcsok). |
| `netUnitPrice` | `nettoEgysegar` | – | Nettó egységár, nettó alapú (B2B) számításhoz. |
| `grossUnitPrice` | – | – | Bruttó egységár, bruttó alapú (B2C) számításhoz. A kassza ebből számolja a nettó egységárat. |
| `quantity` | `mennyiseg` | `1` | Mennyiség. Nem lehet 0, végszámlán és helyesbítőn negatív is lehet. |
| `unit` | `mennyisegiEgyseg` | `'db'` | Mennyiségi egység. |
| `netAmount`, `vatAmount`, `grossAmount` | `nettoErtek`, `afaErtek`, `bruttoErtek` | számolt | Csak akkor add meg, ha pontosan tudod, mit csinálsz. Mindhármat egyszerre kell megadni. |
| `identifier` | `azonosito` | – | Cikkszám vagy termékazonosító. |
| `comment` | `megjegyzes` | – | A tétel megjegyzése. |
| `ledger` | `tetelFokonyv` | – | Könyvelési adatok, lásd lent. |
| `dataDeletionCode` | `torloKod` | – | Adattörlő kód, lásd [Adattörlő kód](/docs/szamla-letrehozas/beallitasok-es-szabalyok/adattorlo-kod). |
| `marginVatBase` | `arresAfaAlap` | – | Különbözeti adózásnál az árrés áfa alapja. |

```ts
items: [
  { name: 'Webfejlesztés', quantity: 10, unit: 'óra', netUnitPrice: 15_000, vat: 27 },
  { name: 'Szakácskönyv', grossUnitPrice: 3_500, vat: 5 },
  { name: 'Kedvezmény', netUnitPrice: -5_000, vat: 27 },
]
```

## Mellékletek (attachments)

Az értesítő e-mailhez legfeljebb 5 fájlt csatolhatsz, fájlonként legfeljebb 2 MB-ot. A mellékletek csak e-mailben mennek ki, ezért a vevőnek kell e-mail cím, és a `sendEmail` nem lehet `false`.

```ts
attachments: [
  { filename: 'aszf.pdf', content: aszfPdf, contentType: 'application/pdf' },
  { filename: 'garancia.txt', content: 'A termékre 2 év garancia vonatkozik.' },
]
```

A `content` lehet `Uint8Array`, `ArrayBuffer`, `Blob` vagy szöveg.

Szállítólevélnél vagy fuvarleveles számlaképnél (`template: 'SzlaFuvarlevelesAlap'`) a `waybill` mező a `fuvarlevel` blokkot tölti ki.

| Mező | XML elem | Leírás |
| --- | --- | --- |
| `courier` | `futarSzolgalat` | `'TOF'`, `'PPP'`, `'SPRINTER'`, `'FOXPOST'`, `'MPL'`, `'GLS'` vagy `'EMPTY'`. |
| `barcode` | `vonalkod` | Általános vonalkód, ha a futárszolgálat saját adatai hiányoznak. |
| `comment` | `megjegyzes` | Megjegyzés a fuvarlevélen. |
| `transOFlex` | `tof` | Trans-o-flex adatok: `id`, `shipmentId`, `packageCount`, `countryCode`, `zip`, `service`. |

## Amit a kassza a küldés előtt ellenőriz

Ezeknél a hibáknál `validation` kategóriájú `SzamlazzError` jön, és kérés nem megy a Számlázz.hu-hoz:

- hiányzik a vevő neve, irányítószáma, települése vagy címe,
- nincs tétel, egy tételnek nincs neve vagy mennyiségi egysége, vagy a mennyisége 0,
- ismeretlen áfakulcs, vagy a `netUnitPrice` és a `grossUnitPrice` egyszerre, vagy egyik sincs megadva,
- a `dueDate` és a `paymentDueInDays` egyszerre szerepel, vagy egy dátum érvénytelen,
- forintos számlán árfolyam, devizás számlán árfolyam nélkül nem MNB bank,
- helyesbítő számla a helyesbített számla száma nélkül, végszámla előlegszámla-szám és rendelésszám nélkül,
- ismeretlen típus, nyelv vagy számlasablon,
- `sendEmail: true` e-mail cím nélkül, melléklet e-mail értesítő nélkül, 5-nél több vagy 2 MB-nál nagyobb melléklet,
- az egyszerűsített számlakép (`simpleItems`) szabályainak megsértése,
- hiányos MPL fuvarlevél adatok.

## Alapértékek a kliensben

A gyakran ismétlődő mezőket nem kell minden hívásnál megadni. A `createKassza({ defaults: { invoice } })` alapértékei akkor érvényesülnek, ha a hívásban az adott mező hiányzik:

```ts
const kassza = createKassza({
  defaults: {
    invoice: {
      prefix: 'WEB',
      paymentDueInDays: 8,
      language: 'hu',
      seller: { bankAccount: '11773016-11111018-00000000', emailReplyTo: 'penzugy@example.hu' },
    },
  },
})
```

Az összes alapértelmezhető mezőt a [Kliens beállítása](/docs/alapok/kliens-beallitasa#alapértelmezések-számlára) oldal sorolja fel.
