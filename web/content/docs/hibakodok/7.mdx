**Üzenet:** Hiányzó adat: ismeretlen számlaszám, rendelésszám vagy külső azonosító.

| | |
| --- | --- |
| Kategória | `not_found` (Nem található) |
| Újrapróbálható | Nem. |
| A kassza hibája | `SzamlazzError`, `code: 7` |

## Mikor jön elő

A hivatkozott bizonylat nem létezik ezen a fiókon.

## Mi a teendő

Ellenőrizd a számot vagy a rendelésszámot. A `find()` metódusok ilyenkor `null`-t adnak hibadobás helyett.

## Kezelés a kasszával

```ts
import { isSzamlazzError } from 'kassza'

try {
  await kassza.invoices.createOnce(szamla)
} catch (error) {
  if (isSzamlazzError(error) && error.code === 7) {
    console.error(error.message, error.hint, error.docsUrl)
    return jelezdEmbernek(error)
  }
  throw error
}
```
