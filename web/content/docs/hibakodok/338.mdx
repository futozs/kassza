description: "A Számlázz.hu Számla Agent 338-as hibakódja: mit jelent, mikor jön elő, és hogyan kezeld a kasszával."
---

**Üzenet:** A hívásazonosító már létezik.

| | |
| --- | --- |
| Kategória | `duplicate` (Már létezik) |
| Újrapróbálható | Nem. A bizonylat valószínűleg már elkészült. |
| A kassza hibája | `SzamlazzError`, `code: 338` |

## Mikor jön elő

Ezzel a rendelésszámmal vagy hívásazonosítóval már készült bizonylat.

## Tipp

Ezzel a callId-val már készült nyugta, kérdezd le a meglévőt.

## Mi a teendő

Ne állítsd ki újra: kérdezd le a meglévőt. A `createOnce()` ezt magától megteszi, és a meglévő bizonylatot adja vissza.

## Kezelés a kasszával

```ts
import { isSzamlazzError } from 'kassza'

try {
  await kassza.invoices.createOnce(szamla)
} catch (error) {
  if (isSzamlazzError(error) && error.code === 338) {
    const meglevo = await kassza.invoices.find({ orderNumber: szamla.orderNumber })
    return meglevo
  }
  throw error
}
```
