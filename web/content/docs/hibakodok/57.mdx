**Üzenet:** XML beolvasási hiba.

| | |
| --- | --- |
| Kategória | `validation` (Hibás adat) |
| Újrapróbálható | Nem. Változatlanul újraküldve ugyanígy elbukik, és a próbálkozások a kitiltási korlátba számítanak. |
| A kassza hibája | `SzamlazzError`, `code: 57` |

## Mikor jön elő

A kérés valamelyik adata nem felel meg a Számlázz.hu szabályainak.

## Tipp

A küldött XML nem felel meg az XSD-nek. A részleteket a hibaüzenet tartalmazza.

## Mi a teendő

Javítsd az adatot a hibaüzenet és a tipp alapján. A kassza a legtöbb ilyen hibát már a kérés elküldése előtt, magyar üzenettel jelzi.

## Kezelés a kasszával

```ts
import { isSzamlazzError } from 'kassza'

try {
  await kassza.invoices.createOnce(szamla)
} catch (error) {
  if (isSzamlazzError(error) && error.code === 57) {
    console.error(error.message, error.hint, error.docsUrl)
    return jelezdEmbernek(error)
  }
  throw error
}
```
