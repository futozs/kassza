---

**Üzenet:** A tesztfiókban túllépted a rövid idő alatt kiállítható bizonylatok számát.

| | |
| --- | --- |
| Kategória | `rate_limit` (Korlát) |
| Újrapróbálható | Csak percek múlva, automatikusan soha. |
| A kassza hibája | `SzamlazzError`, `code: 167` |

## Mikor jön elő

A tesztfiókban rövid idő alatt túl sok bizonylat készült.

## Tipp

Tesztfiókban legfeljebb 500 bizonylat készíthető 10 percenként. Várj néhány percet, ne próbáld újra automatikusan.

## Mi a teendő

Várj néhány percet. Tömeges kiállításnál a `kassza/batch` sebességkorláttal fut, és ennél a hibánál megáll.

## Kezelés a kasszával

```ts
import { isSzamlazzError } from 'kassza'

try {
  await kassza.invoices.createOnce(szamla)
} catch (error) {
  if (isSzamlazzError(error) && error.code === 167) {
    return utemezdKesobbre(szamla)
  }
  throw error
}
```

A hibakódok teljes, hivatalos listája a [Számlázz.hu dokumentációjában](https://docs.szamlazz.hu/hu/agent/basics/error-handling) van. Ez az oldal a kassza `AGENT_ERROR_CODES` táblájából készül.
