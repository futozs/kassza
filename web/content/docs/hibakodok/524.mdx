description: "A Számlázz.hu Számla Agent 524-es hibakódja: mit jelent, mikor jön elő, és hogyan kezeld a kasszával."
---

**Üzenet:** A nyugtaszám-előtag nincs engedélyezve.

| | |
| --- | --- |
| Kategória | `account` (Fiókbeállítás) |
| Újrapróbálható | Nem. Újraküldve is ugyanez lesz. |
| A kassza hibája | `SzamlazzError`, `code: 524` |

## Mikor jön elő

A fiók beállítása, előfizetése vagy jogosultsága nem engedi a műveletet.

## Tipp

A Beállítások / Előtagok oldalon engedélyezd az előtag használatát. Meglévő nyugta sztornója ettől még működik.

## Mi a teendő

Embernek kell a Számlázz.hu felületén rendeznie (előfizetés, beállítás, jogosultság). A kódból ezt nem lehet megoldani.

## Kezelés a kasszával

```ts
import { isSzamlazzError } from 'kassza'

try {
  await kassza.invoices.createOnce(szamla)
} catch (error) {
  if (isSzamlazzError(error) && error.code === 524) {
    console.error(error.message, error.hint, error.docsUrl)
    return jelezdEmbernek(error)
  }
  throw error
}
```
