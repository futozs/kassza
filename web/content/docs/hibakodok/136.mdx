**Üzenet:** Bejelentkezési hiba, lépj be a Számlázz.hu rendszerébe böngészőn keresztül.

| | |
| --- | --- |
| Kategória | `account` (Fiókbeállítás) |
| Újrapróbálható | Nem. Újraküldve is ugyanez lesz. |
| A kassza hibája | `SzamlazzError`, `code: 136` |

## Mikor jön elő

A fiók beállítása, előfizetése vagy jogosultsága nem engedi a műveletet.

## Tipp

Lejárt előfizetés vagy rendezetlen díj. Ellenőrizd a Szolgáltatáscsomagom menüpontot.

## Mi a teendő

Embernek kell a Számlázz.hu felületén rendeznie (előfizetés, beállítás, jogosultság). A kódból ezt nem lehet megoldani.

## Kezelés a kasszával

```ts
import { isSzamlazzError } from 'kassza'

try {
  await kassza.invoices.createOnce(szamla)
} catch (error) {
  if (isSzamlazzError(error) && error.code === 136) {
    console.error(error.message, error.hint, error.docsUrl)
    return jelezdEmbernek(error)
  }
  throw error
}
```
