Sikeres lekérésnél a Számlázz.hu egy `szamla` gyökérelemű XML-t küld (séma: `szamla.xsd`), amelyből a `get()` és a `find()` egy `InvoiceDetails` objektumot épít. Hiba esetén `xmlszamlavalasz` XML jön, abból `SzamlazzError` lesz.

A kassza a válaszon néhány egységesítést végez:

- az üres XML elemekből `undefined` lesz,
- a számokat `number`-ré alakítja, a tizedesvesszőt is kezeli,
- a `true`/`false` és az `1`/`0` értékekből `boolean` lesz,
- a hiányzó listákból (tételek, pénzügyi tételek, címkék, befizetések) üres tömb lesz.

```ts
const szamla = await kassza.invoices.get({ orderNumber: 'REND-1001' })

for (const tetel of szamla.items) console.log(tetel.name, tetel.quantity, tetel.grossAmount)
console.log(szamla.totals.grossAmount, szamla.payments.length)
```

<Callout type="info" title="Típusok importálása">
  Az `InvoiceDetails`, `InvoiceDetailsSeller`, `InvoiceDetailsHeader`, `InvoiceDetailsBuyer`,
  `InvoiceDetailsItem`, `InvoiceDetailsTotals`, `InvoiceDetailsPayment` és `InvoiceDocumentType`
  típust a `kassza` csomagból importálhatod. A többi altípust indexeléssel éred el, például
  `InvoiceDetails['financialItems'][number]`.
</Callout>

## Kötelező elemek

A táblázatokban a nem `undefined` típusú mezőkre számíthatsz. A kassza ezeket az elemeket kötelezőnek veszi:

- `szallito/nev`, `alap/szamlaszam`, `alap/tipus`, `alap/kelt`, `vevo/nev`,
- `osszegek/totalossz` és benne a `netto`, `afa`, `brutto`,
- minden tételnél, pénzügyi tételnél és áfakulcsonkénti összesítésnél a `nev` (ahol van), az `afakulcs`, a `netto`, az `afa` és a `brutto`, a tételeknél a `mennyiseg` és a `nettoegysegar` is,
- minden befizetésnél a `datum`, a `jogcim` és az `osszeg`.

Ha ezek közül valamelyik hiányzik, vagy a gyökérelem nem `szamla`, a kassza nem ad vissza félkész objektumot, hanem `unexpected_response` hibát dob, amelynek az üzenete megnevezi a hiányzó elemet.

## Hibák

| Kód | Kategória | Mikor fordul elő? |
| --- | --- | --- |
| – | `validation` | Üres hivatkozás, vagy nem pontosan egy kulcs a hivatkozásban. Kérés nem megy ki. |
| 1 | `maintenance` | Karbantartás. A kassza magától újrapróbálja. |
| 3 | `auth` | Hibás Agent kulcs. |
| 7 | `not_found` | Nincs ilyen számlaszám, rendelésszám vagy külső azonosító. A `find()` ilyenkor `null`-t ad. |
| – | `network`, `timeout` | Hálózati hiba vagy időtúllépés. A kassza magától újrapróbálja, és csak az utolsó sikertelen próbálkozás után dob. |
| – | `unexpected_response` | A válasz nem `szamla` XML, hiányzik belőle egy kötelező elem, vagy a PDF nem érvényes Base64. |

```ts
import { isSzamlazzError } from 'kassza'

try {
  const szamla = await kassza.invoices.get(szamlaszam)
  console.log(szamla.header.reversed)
} catch (error) {
  if (isSzamlazzError(error) && error.isNotFound) console.warn(`Nincs ilyen számla: ${szamlaszam}`)
  else throw error
}
```

Az összes kódot a [Hibakezelés, hibakódok](/docs/alapok/hibakezeles#hibakódok) oldal sorolja fel.
