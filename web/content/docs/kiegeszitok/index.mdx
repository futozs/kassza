A fő `kassza` modul a Számla Agent hívásait intézi. A körülötte lévő feladatokra külön alcsomagok vannak, amelyeket csak akkor importálsz, ha kellenek. Egyiknek sincs futásidejű függősége, és a `kassza/storage/fs` kivételével egyik sem használ Node.js API-t.

| Alcsomag | Mire való? |
| --- | --- |
| `kassza/testing` | Mock kliens és hamis Számla Agent hálózat és Agent kulcs nélküli tesztekhez |
| `kassza/validators` | Adószám, bankszámla, IBAN, EU adószám, e-mail és cím ellenőrzése |
| `kassza/money` | A számlán használt kerekítés és összegzés a saját kódodban |
| `kassza/storage`, `kassza/storage/fs` | A bizonylat PDF mentése S3-ba, R2-be, Vercel Blobba, Supabase-be vagy lemezre |
| `kassza/cookie-stores` | Közös munkamenet-tároló serverless és edge környezethez |
| `kassza/ipn` | A Számlázz.hu fizetési értesítéseinek fogadása |
| `kassza/payments` és szolgáltatónként `kassza/payments/stripe`, `…/simplepay`, `…/barion`, `…/revolut`, `…/paypal` | [Fizetésből bizonylat](/docs/fizetesek): webhookok és `issueForPayment` |
| `kassza/reports`, `kassza/nav` | [NAV nyugta-adatszolgáltatás](/docs/nav-nyugta): napi összesítő, NAV kliens, egyeztetés |
| `kassza/delegation` | [Megbízotti számlázás](/docs/megbizott-szamlazas) sok cég nevében |
| `kassza/data-link` | A [pénzügyi adatkapcsolat](/docs/adatkapcsolat) fogadása |
| `kassza/mcp` | [MCP szerver](/docs/kiegeszitok/mcp-szerver) AI asszisztenseknek, saját átvitellel |

A csomag egy `kassza` parancsot is ad (`npx kassza`), lásd [Parancssor](/docs/kiegeszitok/parancssor).
